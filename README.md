# 👻 GhostCloud

A featherweight, haunted-holiday **SoundCloud** desktop client for Windows.
Built on Tauri 2 + Rust: a ~4 MB installer, near-zero idle CPU, and a pile of extras:
a built-in 10-band EQ, waveform seek bar, spectrum visualizer, timed comments, local files,
playlists, FX themes, Discord Rich Presence and signed auto-updates.

## ⬇ Download

Grab **GhostCloud_x.y.z_x64-setup.exe** from the [latest release](../../releases/latest).

- Installs per-user, no admin needed.
- Windows SmartScreen may warn about an unrecognized app (the build isn't code-signed yet):
  click **More info → Run anyway**.
- Already installed? GhostCloud updates itself: it checks this page at most every 6 hours
  and offers **update & restart**. Every update is signature-checked.
